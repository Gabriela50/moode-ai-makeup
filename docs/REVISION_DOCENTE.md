# Revision docente - MOODE

## Componentes
Aplicacion web con Vite y JavaScript.
Aplicacion movil con React Native, Expo y WebView.
Supabase para autenticacion y datos.
MediaPipe para reconocimiento facial.

## Verificacion automatizada
Ejecutar npm test y npm run build.

## Demostracion funcional pendiente
- Probar registro e inicio de sesion.
- Abrir la camara en un dispositivo Android.
- Comprobar maquillaje y seleccion de fotografias.
- Verificar guardados, historial, idioma y tema.
- Confirmar que la APK distribuida sea la version probada.

## Limitaciones
Una compilacion web correcta no demuestra que la APK funcione.
